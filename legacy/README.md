# Les pages d'origine

Ces fichiers sont le site tel qu'il était avant la refonte du 27 août 2026.
Ils ne sont plus servis : les cinq pages actuelles les remplacent, et les
anciennes URL redirigent.

On les garde parce qu'ils sont la **source** de `data/*.js` : `tools/extract.mjs`
les relit à chaque exécution. Les supprimer rendrait l'extraction impossible à
rejouer, et donc impossible à corriger.
